## Install

1. Copy everything into the profile repository.
2. Push to `main`.
3. Open **Actions**.
4. Run **GitHub Profile 3D Contrib** once.
5. Run **Generate Contribution Snake** once.
6. Refresh the GitHub profile after both workflows finish.

The README links to these real repositories:
- KnowledgeOS
- e-commerce
- football_analytics
- FakeNews_predict
- Job_Assistant
- Vector-based-Product-FAQ-Assistant
- PatientRecords
- LeetCode

The `profile-3d-contrib` folder is generated by GitHub Actions.
The snake assets are published to the `output` branch.
