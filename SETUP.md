## After pushing

1. Open GitHub → Actions.
2. Run `GitHub Profile 3D Contrib`.
3. Run `Generate Contribution Snake`.
4. For `GitHub Metrics`, create a repository secret named `METRICS_TOKEN` containing a GitHub personal access token with the permissions required by the metrics action.
5. Refresh your GitHub profile after the workflows complete.

Note: the 3D workflow replaces the placeholder contents in `profile-3d-contrib/` with generated SVGs.
